# Contributing to DevBoost AI

We'd love your help to make DevBoost AI better! Since this is an open-source project, all contributions—from bug reports to new features—are highly appreciated.

## Getting Started

1. **Fork the repository** on GitHub.
2. **Clone your fork** locally: `git clone https://github.com/your-username/devboost-ai.git`
3. **Install dependencies**: `npm install`
4. **Run the dev server**: `npm run dev`

## How to Contribute

- **Report Bugs**: Check existing issues, and if you don't see your problem, open a new issue.
- **Suggest Features**: Have an idea for a new AI developer tool? Open an issue and let's discuss it!
- **Submit Pull Requests**:
  1. Create a new branch: `git checkout -b feature/your-feature-name`
  2. Make your changes and commit them: `git commit -m "Add some feature"`
  3. Push to your branch: `git push origin feature/your-feature-name`
  4. Open a Pull Request against the `main` branch.

## Coding Guidelines
- We use **Next.js 15 App Router** and **Tailwind CSS**.
- Keep the UI aesthetic clean, dark, and professional.
- Ensure all components are responsive.

Thank you for helping developers build better!
