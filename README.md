## ✨ Features

- **Prompt Optimizer**: Transform any short prompt into a detailed, expert-level prompt for LLMs.
- **Token Counter**: Estimate token counts for GPT, Claude, and Gemini instantly.
- **JSON Formatter**: Paste ugly JSON. Press format. Done. Clean and accessible.
- **AI Cost Calculator**: Calculate precise API costs for Claude, GPT, and Gemini based on token usage.
- **Markdown ↔ HTML Converter**: Instantly convert markdown to raw HTML.
- **Base64 Encoder/Decoder**: Fast utility to encode and decode base64 strings.

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/shreyamdash/devboost-ai.git

# Navigate to project
cd devboost-ai

# Install dependencies
npm install

# Run the development server
npm run dev
```
