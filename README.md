# DevBoost AI

Open-source AI toolkit for developers.

## Features

✅ **Prompt Optimizer**
Transform any short prompt into a detailed, expert-level prompt for LLMs.

✅ **Token Counter**
Estimate token counts for GPT, Claude, and Gemini instantly.

✅ **JSON Formatter**
Paste ugly JSON. Press format. Done.
